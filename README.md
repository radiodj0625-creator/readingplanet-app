# 리딩플래닛 학원 태블릿 앱

학원 갤럭시탭에서 주소로 여는 학습 앱 두 개.

- `index.html` — 첫 화면 (문장 연습 · 라이팅)
- `sentence.html` — 문장 연습 1–12권 (144과)
- `writing.html` — 라이팅 1–6권 (72과)

파일 하나로 도는 오프라인 앱이고, 학습 기록은 그 기기 브라우저(localStorage)에만 쌓인다.
원본과 과 자료 · 생성기는 `C:\리딩플래닛\클로드워크북\7_문장쓰기\앱` · `6_라이팅\앱`.
새 판을 만들면 같은 이름으로 덮어쓰고 push 한다.
